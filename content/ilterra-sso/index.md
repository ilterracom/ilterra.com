## ilTerra SSO plugin for WordPress

ilTerra SSO is a lightweight, secure sign-in plugin that lets visitors log in to your WordPress site via Microsoft Entra ID (formerly Azure AD) using the OpenID Connect protocol. Enjoy simple setup, flexible access controls, and a modern, password-free UX.

## Key Benefits

- **Fast sign-in with Microsoft**  
  Users authenticate in one click with their corporate or personal Entra ID account.
- **Granular security controls**  
  Hide the default username/password fields on the WordPress login page.  
  Rate-limit login attempts per IP address.
- **Automatic user provisioning**  
  If a matching WordPress account doesn’t exist, the plugin creates one automatically with the **Subscriber** role—while keeping all the advantages of SSO.
- **Friendly settings page**  
  The plugin adds its own page in the WordPress admin with two tabs:  
  **General** — control login behavior and IP restrictions.  
  **Microsoft Entra ID** — configure your app (Client ID, Secret, Tenant/Issuer, Scopes) and run a one-click test authorization.

## Who ilTerra SSO Is For

- **Corporate sites** that need centralized user management through Microsoft 365 / Azure.
- **SaaS products and private portals** that require convenient, reliable sign-in with minimal friction.
- **Blog and community owners** who prefer Microsoft accounts over local passwords.

## How Sign-In Works

1. A **“Login with Microsoft”** button appears on the WordPress login page.
2. The user is redirected to Microsoft’s sign-in page and grants access.
3. After a successful return to your site:
   - Existing users are signed in.
   - New users are created automatically with the **Subscriber** role.
